## 9. Hands-on Practice

Along with learning the concepts, hands-on experience is essential. Below are practical exercises you should try:

1. **Create and manage an S3 bucket**: Upload data to S3, set permissions, and access the data.
2. **Launch an EC2 instance**: Set up an EC2 instance, install necessary tools (like Python, libraries), and run a data science script.
3. **Deploy a Lambda function**: Create a Lambda function that triggers when new data is uploaded to an S3 bucket.
4. **Train a model on SageMaker**: Train a simple machine learning model (e.g., linear regression) on a dataset using SageMaker.
5. **Set up an ETL job on AWS Glue**: Process data from S3, clean it, and save it back to S3.
6. **Deploy a Flask app on Elastic Beanstalk**: Create a simple API using Flask and deploy it on Elastic Beanstalk.
